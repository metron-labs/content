#### Integrations

##### Flare Exposure Event Collector

- Added a Flare event collector that polls the tenant event feed and stores events in the `flare_exposure_events_raw` dataset.

#### Parsing Rules

##### Flare Exposure Parsing Rule

- Added a parsing rule that sets the event time from the Flare `matched_at` field.

#### Modeling Rules

##### Flare Exposure Modeling Rule

- Added a modeling rule that maps Flare events onto the Cortex Data Model, including the identifier used to group alerts into a case.

#### Correlation Rules

##### Flare Exposure

- Added real-time correlation rules that open one alert per Flare event, split by Flare severity so the rules do not overlap.
