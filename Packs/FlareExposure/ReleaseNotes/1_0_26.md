#### Integrations

##### Flare Exposure Event Collector

- Fetch events now continues from the timestamp of the last stored event.
- Fetch Via Alerts keeps one timestamp per category on each Flare alert. A category added to an alert after the first run starts at the global timestamp.
- Closing a Flare Exposure case no longer waits for the next event fetch. The case-closure playbook marks the Flare events remediated when the case is resolved.
- Flare API paths and request headers are shared constants. The category list now includes the Flare event type groups.

#### Playbooks

##### Flare Exposure - Case Closure Status Write-back

- The playbook now runs the Flare status update when the case is resolved. The event fetch no longer sends that update.
