#### Integrations

##### Flare

- Renamed `flare-exposure-get-events` to `flare-get-events`.
- Added the `flare-get-event-details` command. It returns one Flare event, including its data block, with password fields removed.
- Added the `flare-get-profile` command. It returns the Flare account profile for the configured API key.
- Added the `flare-get-tenants` command. It lists the Flare tenants that API key can access.
- Added the `flare-get-credentials` command. It returns one page of leaked credentials for a tenant, with password fields removed.
