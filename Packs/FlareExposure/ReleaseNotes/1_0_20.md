#### Integrations

##### Flare Exposure Event Collector

- Added **Enable Status Write-back - Auto Closure/Remediation**. When it is checked, closing a Flare Exposure case marks the Flare events on that case as remediated.
- Added the `flare-update-event-status` command to mark a Flare event remediated on demand.

#### Playbooks

##### New: Flare Exposure - Case Closure Status Write-back

- Runs `flare-update-event-status` for the Flare events on the current case.
