
#### Parsing Rules

##### Flare Parsing Rule

- Sets the event time to the moment the event arrives in XSIAM. The Flare match time stays in `matched_at`, so a backfilled event still opens an issue.

#### Correlation Rules

##### Flare - Critical

- The 24-hour window follows the arrival time, so each stored event opens an issue.

##### Flare - High

- The 24-hour window follows the arrival time.

##### Flare - Medium

- The 24-hour window follows the arrival time.

##### Flare - Low

- The 24-hour window follows the arrival time.

##### Flare - Info

- The 24-hour window follows the arrival time.
