
#### Integrations

##### SpecterOps BloodHound Enterprise

- Added the **bloodhound-principal-impact-get** command to return principal risk details, the domain grid, or the radius target list for User, Computer, and Group indicators.
- Added the **Create indicators** setting. When enabled (default), fetch creates or updates User, Computer, and Group indicators for principals on newly ingested attack paths.
- If indicator creation fails while **Create indicators** is enabled, fetch retries the same BloodHound findings on the next run instead of advancing the fetch cursor.
- See the integration instance help for Threat Intel **Delete** vs **Delete and exclude** when indicators do not reappear after fetch.

#### Scripts

##### SpecterOpsBloodHoundEnterpriseUpdateRisk

- Added the **Update BHE Risk** indicator action. It writes principal risk details and the domain grid to the indicator layout.
- Labeled the principal time as BloodHound last seen and added the time the risk section was saved.

##### SpecterOpsBloodHoundEnterprisePullRadius

- Added the **Pull BHE Radius** indicator action. It writes the radius target list to the indicator layout.
- Added the time the radius section was saved.

##### SpecterOpsBloodHoundEnterpriseShowRisk

- Added the indicator section that renders the stored risk details.

##### SpecterOpsBloodHoundEnterpriseShowRadius

- Added the indicator section that renders the stored radius targets.
