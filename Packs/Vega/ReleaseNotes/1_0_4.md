#### Integrations

##### Vega

- Added **vega-get-alerts** and **vega-get-incidents** commands to fetch Vega objects by API id and/or created-at time range, with optional XSOAR incident payload preparation for recovery.
- Added `to` time support for Vega alert and incident API queries.

#### Scripts

##### VegaReconcileIncidents

New: **VegaReconcileIncidents**. Reconciles Vega alerts and incidents against Cortex XSOAR for a Vega source-system time range and reports missing IDs as copyable lists for follow-up creation commands.

#### Incident Fields

##### Vega Incident ID

Made **Vega Incident ID** (`vegaincidentid`) searchable so reconciliation can match Vega incidents in XSOAR.

##### Vega Created At

Made **Vega Created At** (`vegacreatedat`) searchable so source-system timestamps can be queried.
